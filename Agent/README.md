# FlyGo Agent

This folder contains a starter scaffold for a local FlyGo project agent.

## Purpose

- Provide a simple agent structure for future automation, project helpers, or assistant integration.
- Serve as a base for expanding into a full AI-powered workflow.

## Files

- `agent-config.json`: metadata and capabilities for the agent.
- `agent.js`: minimal Node.js stub demonstrating agent structure.

## Next steps

1. Add an implementation for your preferred AI platform (OpenAI, local model, etc.).
2. Extend `agent.js` with commands for project-specific tasks like building, linting, or generating UI.
3. Optionally add a `package.json` and dependencies if you want to run the agent locally.
