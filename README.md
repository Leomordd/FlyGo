# ✈️ Travel Agency

Aplicación web de gestión de viajes desarrollada con React, Node.js y PostgreSQL.

## 🚀 Características

- 🔐 Autenticación de usuarios
- 📍 Gestión de destinos
- 📅 Reservas de viajes
- 👤 Roles de usuario
- 📊 Panel administrativo

## 🛠️ Tecnologías

**Frontend**
- React
- Tailwind CSS
- Axios

**Backend**
- Node.js
- Express

**Base de datos**
- PostgreSQL
